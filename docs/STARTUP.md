# Connect & start

Run `& C:\QuantaCore\Start-Quanta.ps1` under the Windows account that owns the protected credentials, then open http://127.0.0.1:3000/#/startup. The complete backend serves both UI and API. A frontend preview cannot save connections or authorize accounts.

Mission Control shows the startup check once per browser session. It reads provider configuration and optional runtime health automatically. Choose a saved text route, then explicitly run Test reply & use for text agents. This sends a small READY prompt and saves the preferred provider only after usable text returns. Changing the route or refreshing clears verification. No model test or task runs automatically.

The ChatGPT plan panel remains separate from compatible API routes and uses its own account-bound test; signing in does not enable API billing. Agents and external tools retain their own task contracts, permissions, and review steps. HTTP availability is not proof of tool execution. Optional local services may be absent while a connected cloud text model works. Continue with setup pending keeps the app accessible.
