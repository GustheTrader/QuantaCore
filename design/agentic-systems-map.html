Model ≠ harness ≠ tool

The model produces a response. The harness controls a work loop. Tools perform operations. Permission checks belong at the adapter and runtime boundary.

Memory ≠ training

Hindsight retrieves admitted context. Skills revise procedures. RRSI searches harness instructions. Weight training is a separate provider job; no deployed weight RL is established here.

HNTL before adoption

Human Near the Loop: capture evidence, compare frozen versions, inspect critical failures, approve a future version and retain rollback. A model critique alone does not validate a result.
