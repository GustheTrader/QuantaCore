How the lab works

Build a hypothesis, then measure it

Select a base system and signal families. AND means every selected signal is required; OR means any selected signal can confirm. Save measured results for that exact combination. The lab does not execute strategies or infer combined performance from separate tests.

Keep the comparison fair

A matched comparison requires the same instrument / venue, timeframe, dates, session, starting capital, sizing, cost assumptions, test phase, and Sharpe convention. Mismatches are shown in Compare. A baseline is a measured test you select; deltas do not prove causality.

Metric conventions

Return is total equity return over the entered dates, in percentage points. Max drawdown is the positive peak-to-trough equity loss percentage. Hit rate is winning trades / closed trades. Enter Sharpe and Sortino from your test engine, with their return frequency, annualization factor, and risk-free / target assumptions. They cannot be reconstructed from hit rate and trade count.

Calmar is calculated as annualized compound return / max drawdown, using elapsed calendar days / 365.25. A zero drawdown or invalid period has no Calmar. Profit factor = gross profit / absolute gross loss. Expectancy R = mean net trade P&L / initial risk, measured by your engine.

Qualifying is a research filter

The editable gates use trade count, drawdown, Sharpe, costs, and test phase. Passing gates is a reason to investigate further, not a guarantee or significance test. Paper results need a holdout or walk-forward test. There is no universal minimum sample size.

Your data

The hosted website is private. Test records are stored locally in this browser and do not sync between devices. Export a JSON workspace backup, then import it elsewhere to transfer records. CSV exports include all stored metrics. Demo rows remain labeled when exported and reimported.

Starting catalog

Presets name the systems and sleeves from prior QS research; they contain no executable strategy or verified rule sheet. The 2m / 1m reclaim is a proposed variant. Add a custom system when your inventory changes.
