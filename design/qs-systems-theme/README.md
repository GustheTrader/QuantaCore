# Quanta theme for QS Terminal Systems Lab

Target: https://qs-terminal-systems-lab.brisk-beech-3852.chatgpt.site/#results

`quanta-theme.css` is an additive presentation layer for the original application. Load it after `styles.css`. It uses the existing selectors and CSS variables, preserving application scripts, form controls, storage keys, imports, records and research logic.

The palette matches QuantaCore: navy `#020617` / `#081225`, cyan `#22d3ee`, blue `#60a5fa`, orange `#fb923c`, violet `#a78bfa` and emerald `#34d399`. The theme styles navigation, the gradient hero, cards, forms, charts, tables, comparison tray, shortlist, dialogs and status messages. It includes keyboard focus and reduced-motion support.

`preview.html` is a static snapshot of the visible hosted results page with the new theme. It contains the original eight labelled synthetic demo records. Application scripts were removed; controls in this snapshot are for visual inspection. It does not copy browser storage or access credentials, execute a backtest or synchronize data. `base.css` is the observed original public stylesheet, retained only for the local design preview.

Do not create a replacement site or deploy to a different project ID. Once the correct site's editing access is available, open its source with the Sites workflow, add `quanta-theme.css`, link it after the existing stylesheet, package the unchanged app logic and publish to the existing audience and URL.
